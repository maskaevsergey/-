## Что ты найдёшь в этом профиле

- **Проектные артефакты аналитика:** ЧТЗ, ПМИ (программы и методики испытаний), тест‑кейсы, инструкции пользователей.
- **Модели бизнес‑процессов:** схемы as‑is/to‑be, маршруты согласований, ролевые модели.
- **Материалы по переходу с Excel:** шаблоны ввода начальных остатков, маппинг полей, контрольные списки.

## Ключевые проекты

- **Перевод учёта спецодежды, инвентаря и спецоснастки в 1С:ERP** (ООО «Спец‑Монтаж»): анализ требований, выявление функциональных разрывов, проектирование доработок с минимальным изменением типовой конфигурации, постановка задач разработчику, подготовка ПМИ и инструкций.
- **Автоматизация согласования заказов поставщикам** (лимит 100 000 ₽, несколько уровней согласования): проектирование маршрутов, реестр требований, ЧТЗ, тест‑кейсы.
- **Адаптация закупочного процесса филиала под 1С:ERP:** обследование по документам, сопоставление с типовым функционалом, выделение типовых механизмов и зон доработки, подготовка ТЗ.
